## 👋 Sobre nosotros

Basilicon Tech nace de la mano de **Miguel Ángel Moreno** y **Alfonso Ismael Manzano**, dos desarrolladores con una visión clara: usar la tecnología para resolver problemas reales, sin artificios ni complejidad innecesaria.

Somos especialistas en **desarrollo Full Stack con integración de Inteligencia Artificial**. Creamos aplicaciones web a medida para empresas y profesionales que quieren digitalizar procesos, mejorar su eficiencia y dar el salto tecnológico que realmente necesitan.

Abordamos cada proyecto de forma integral: desde el análisis de las necesidades hasta su puesta en producción. Y cuando hablamos de IA, lo hacemos con criterio: solo la integramos cuando aporta un valor real al proyecto, no porque esté de moda.

## 🚀 Proyectos destacados

### 📊 Data Analyst

**[CriptoRadar — Análisis de criptomonedas](https://github.com/basilicontech/criptoradar)**
Aplicación para monitorizar la evolución del mercado de criptomonedas y stablecoins usando las APIs de Bitget y DefiLlama. Permite explorar precios históricos, volumen de negociación, capitalización de mercado, estabilidad del peg de stablecoins y generar visualizaciones interactivas.
`Python` · `Streamlit` · `Pandas` · `Plotly` · `Seaborn` · `Requests` · `APIs`

### 💻 Web Development

**[GeoPesca](https://github.com/basilicontech/geopesca)**
Sistema de Información Geográfica para la comunidad pescadora deportiva. Permite registrar y visualizar jornadas de pesca individuales y concursos organizados por clubes sobre un mapa interactivo de la Península Ibérica, con filtros, gestión para administradores y registro de nuevas actividades.
`JavaScript` · `Leaflet` · `HTML` · `CSS` · `PostgreSQL`

**Azahar Limpieza**
Sitio web para dar a conocer un servicio especializado en preparación y mantenimiento de alojamientos turísticos. Desarrollado en WordPress con el tema Astra, formulario de contacto vía Contact Form 7 y envío de correos gestionado con WP Mail SMTP.
`WordPress` · `Astra` · `Contact Form 7` · `WP Mail SMTP`
